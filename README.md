# GymForza Access

GymForza Access is an Android application created for the Gym Forza access-management project. It provides a mobile way to interact with the gym's QR-based access system.

## About the app

The project is focused on making gym entry more practical by using QR codes as part of the access process. The app is intended for use within the Gym Forza environment and its connected system.

## Main purpose

- Support QR-based gym access.
- Connect the mobile experience with the Gym Forza access system.
- Provide a dedicated Android app for the Gym Forza project.

## Platform

- Android

## Important information

GymForza Access is intended to work with the Gym Forza system. Access availability may depend on the gym's configuration and the services connected to the application.
